# レビューの指標

レビューの教材と手順が働いているかを、観察の記録として測ります。**指標を目標にしません。** とくに「テンプレート外の指摘が減る」を成功の印にしません（#11 のレビュー記録。0 件が続くのは、一覧の外を見なくなった警告とみなす）。

- 作成方法：本資料は生成AI（Claude）を使って作成し、筆者が確認して公開しています。人による点検は未実施
- 指標の選び方は筆者の提案です（追跡 #5）

| 指標 | 測り方 | 読み方 |
| --- | --- | --- |
| 指摘の件数（出どころ × 種別 × 重大度） | レビューレポートの 2. を集計する | 出どころ「観点」が多いのは問いが働いている印。「テンプレート外」が 0 件のレビューが続いたら、段 5 を見直す |
| 目的と仕組みの不一致の件数と、取り違えた問い | レポートの「取り違えた問い」の列 | 同じ問いの取り違えが繰り返されるなら、対比表と判断の木を直す |
| 問いの回答の分布 | レポートの 1. の「問いの回答」 | 「該当なし」が多い段は、問いが設計の種類に合っていない |
| 判定できなかった問いの数 | 見る欄が空で No にした問い | 多いなら、テンプレートの欄が足りない（#4 に戻す） |
| 再発見の率（較正） | 既知の指摘のある設計書を、教材を使って改めてレビューし、既知の指摘のうち見つけた割合 | 見逃した指摘は、問いを足す材料。率は 1 回のレビューの数で、母数の正解ではない |
| レビュー後の欠陥の件数（区分別） | [escaped_defects.md](escaped_defects.md) | 「問いが無い」「欄が無い」が続くなら、観点書・テンプレートの穴 |
| 理由の採点の一致率 | 同じ理由を 2 回独立に採点し、観点ごとの一致の割合を出す（`research/reviews/rubric-agreement-2026-11-23.md`） | 低い観点は、観点の文と例を直す |
| LLM の指摘の採用率 | 出どころ「LLM」の指摘のうち、レビュアーが採用した割合 | 低いなら一次スクリーニングの指示を見直す。高くても人の確認を省かない |
| レビューにかかった時間 | 段ごとに記録する | #9 のパイロットで、段の順序と時間の目安を直す |
