# 追加前の 25 問：`https://minato-denki.example/claims/` の `customer_ref`

> **意図的に誤りを含む教材。設計に使わない**

- 対象：台帳の `C-customer-ref`（claims.yaml）
- 判定：共有クレームにする（25 問すべてに答えた）

| # | 問い（スライド 142・143） | 回答 | 出どころ |
| --- | --- | --- | --- |
| 1 | 受け手はこのクレームで何を決めるか | 案件の顧客の返金・配送先だけを扱わせる（usage は identifier）。refund-tool は返金の対象の注文の顧客と照合し、customer-tool は顧客の DB の行を引く。order-tool は監査のために受ける | 台帳：`usage`・`answers`・`rationale` |
| 2 | 寿命中に値が変わっても困らないか | 困らない（volatility は never）。案件の顧客は変わらない | 台帳：`volatility`・`on_revoke` |
| 3 | 既存の標準クレームで表せないか | 表せない。操作の対象の顧客を指す登録名が無く、sub は担当者に使っている（prior_art_search） | 台帳：`registered_ref`・`prior_art_search` |
| 4 | 自組織の名前空間か。予約名と衝突しないか | 自組織の名前空間 https://minato-denki.example/claims/ の下。IANA の登録名と衝突しない | 手書き |
| 5 | 「.」「/」入りの名前を全ての受け手のツールで参照できるか | 受け手はどれも組織の共通の検証部品で、名前を完全一致の文字列のキーとして読む | 手書き |
| 6 | トップレベルか、組織のオブジェクトの下か | トップレベルに、名前空間の接頭辞つきの名前で置く（flat_prefix） | 台帳：`namespace`・`shape` |
| 7 | 型は 1 つか。区切り文字列を避けたか | 文字列 1 つ（shape は single） | 台帳：`type`・`shape` |
| 8 | ID・金額は文字列で運ぶか | 文字列で運ぶ（cr_ と 22 文字の英数字） | 手書き |

| 10 | 大文字小文字・空白・比較方法は | 大文字小文字を区別し、完全一致で比べる。正規表現 ^cr_[A-Za-z0-9]{22}$ に合わない値を拒否する | 手書き |
| 11 | 誰が値を書けるか。自己申告と分けたか | agent-sts だけが、case_id で案件の管理から引いた値を書く。エージェントの要求の値は使わない | 台帳：`authoritative_writer`・`provenance` |
| 12 | 名前と不変の ID を出し、ID で照合させるか | 顧客の名前は出さない（連絡先は customer_contact で知らせの宛先にだけ使う）。不変の参照で照合する | 手書き |
| 13 | 上限は。超えたら失敗か、欠落か | 25 バイトで固定（上限で固定） | 台帳：`max_bytes`・`max_items`・`overflow_strategy` |
| 14 | 全リクエストに載せる価値があるか。宛先ごとに絞れるか | 3 つのツールのどれも、操作の対象の顧客の照合に要る | 手書き |
| 15 | 付与するのは単一の発行者だけか | agent-sts だけ（issuers） | 台帳：`issuers`・`enforced_at` |
| 16 | 検証を共通ライブラリで提供するか | 提供する。形式の検査は共通の検証部品、注文・顧客の照合は各ツールの DB の問い合わせ | 手書き |
| 17 | ヘッダーに移すとき、同名ヘッダーの偽装（大文字小文字・アンダースコアの変種・重複）を除去するか | ヘッダーに移さない | 手書き |
| 18 | 未検証の値を流すモードは無いか | 無い | 手書き |
| 19 | 知らない受け手が無視しても安全か | 返金と配送先の変更をするツールでは安全ではない（他人の顧客を操作させうる）。そうしたツールは照合を必須にしてから受け手に足す。照会のツールは注文の ID で引く | 手書き |
| 20 | ログに残すか。値かハッシュか。個人情報か | 個人情報（顧客の DB と容易に照合できる）。ログには鍵つきのハッシュで残す | 台帳：`log_policy`・`pii_category` |

| 24 | 改名・廃止の互換期間と並行発行は | TOOL_AT の受け入れの上限（1830 秒）より長く、少なくとも 2 週間は並行して出す | 手書き |
