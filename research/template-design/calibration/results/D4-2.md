サンプル行（種 12）の C-authorization-details・C-azp・C-client-id を中心に、designs/target の設計書と YAML を読みました。指摘は 20 件（Major 9・Minor 11、Blocker なし）です。

**1. 性質の表（12. 2. 6. と照らした結果）**
- 「長時間・非同期の処理がある＝当たらない」は誤りです。REQ-11 の予約の返金（最大 2 時間後）は、refund-batch が実行します（U13 を「該当」と答えています）。台帳に long_running も、この経路のホップも無いため、機械が見落としました。F1 とし、q-long-running を足して答えました。
- そのほかの 11 行は図・要求と合っていました。ただし「発行者が複数」の根拠にある catalog_answers.yaml の idp には SPIRE（AGENT_SVID の発行者）がありません（F17）。
- 図に無い部品が 4 つあります。approval-console（承認の画面）、旧いマクロの道具、予約の委任の記録の保存先、refund-batch が返金を実行する経路です（F3・F9・F10）。

**2. 6. の「要る」と判断の木**
- 次の対応は木の節と合っていました。
  - q-sub・q-actor・q-agent → keep-sub-exchange（sub を保つ・act・client_id）
  - q-peer → peer-mtls（mTLS の SVID で確かめ、トークンでは代えていない）
  - q-resource → aud が 1 つ
  - q-holder → cnf
  - q-authorized → rar-vs-custom（承認は authorization_details、ロールは PDP に問い合わせ）
  - q-txn → case_id（txn は検討したうえで却下し、理由を書いている）
- 合わなかったのは 3 か所です。
  - UC3 の q-actor を「不要」としているが、予約の返金は refund-batch が代わりに実行する（F13）
  - 3 万円以下の返金を scope だけで通している（対比表 scope-vs-role の m-3、F2）
  - C-roles と C-groups の代わりの行を C-scope としている（F14）

**3. 開いた問い 3 つ（辿った範囲と気づき）**
- **op-proof-holder**
  - 辿った範囲：cnf を照合する 3 つのツール、agent-sts での束縛、TOOL_AT の 3 つの経路（コンソール・エージェント・サブエージェント）、DELEG_AT、STAFF_AT。
  - 3 つの経路とも、cnf は交換を求めた mTLS の相手の証明書で、ツールを呼ぶ相手と一致します。DELEG_AT は束縛が無い代わりに、may_act と mTLS で使える相手を限っています。
  - 気づき：SVID は 1 時間ごとに更新されます。更新の後、TLS は新しい証明書を使うので、古い証明書に束縛した TOOL_AT は期限前でも cnf が合わなくなります。設計書の「止まらない」には根拠がありません（F15）。
- **op-source-change**
  - 出来事：異動による refund-operator の剥奪。
  - 辿った範囲：人事の台帳 → hr-sync（120 秒。測っていない） → Keycloak のロールの割り当て → PDP（キャッシュ 30 秒） → refund-tool と agent-sts。
  - 気づき 1：誰も時間を約束していない区間がある。人事連携の事象が止まった場合、夜間の全件同期まで遅れ、警報は 10 分です（F7）。
  - 気づき 2：図に無い書き込みの経路がある。レルムの管理者が直接書き換える経路と、チームのリーダーが管理するグループに付いたロールです。緊急に手で剥奪しても、夜間の全件同期で戻るおそれがあります（F8）。
- **op-one-time**
  - 辿った範囲：承認、3 万円以下の返金、TOOL_AT の jti、LOGOUT_TOKEN、AUTH_CODE。
  - 並行の 2 件：条件つきの更新で 1 回だけ消費するので安全です。
  - 通信が切れた後の再送：approval_id を冪等キーにしているので、承認つきの返金は安全です。ただし「決済代行への返金が失敗したら未使用に戻す」は、結果が分からない（タイムアウトの）場合に 2 回返金になります。
  - 予約の返金：承認をいつ消費するかが書かれていません。
  - 3 万円以下の返金：冪等キーが決まっていません（F4・F5）。
