# 2 組目の教材（#82）：誤りを埋め込んだ設計書と対照

> **意図的に誤りを含む教材。設計に使わない**
>
> `seeded-c/`・`seeded-d/` の設計書には、問いの取り違えを意図的に埋め込んでいます。`control-c/`・`control-d/` は測定の対照に使う架空のシステムの設計書で、実在のシステムの設計ではありません。どれも、写して設計に使わないでください。

> **LLM による作成。人による検証ではない。**
> 設計書・対照の清掃・正解の一覧・目立ちやすさの区分は、どれも LLM（Claude Opus 5.5）のセッションが作りました。人は 1 件も確かめていません（#20）。
